# Social icons

- `x`, `youtube`, `facebook`, `instagram` and `discord`: paths from [Simple Icons](https://simpleicons.org/), version 16.38.1, distributed under [CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). The respective names and marks belong to their owners.
- `japan-support`: the headset path from the Japanese official launcher's `MediaIconReport` in `out/renderer/assets/main-4217f8b0.js`. The background circle was removed and the path rendered white. This artwork belongs to its respective rights holders. The launcher identifies `https://www.azurpromilia.jp/contact` as its support link.

Each SVG has an 80 × 80 transparent canvas with its symbol centered in a 56 × 56 area; matching PNGs were rendered using `@resvg/resvg-js`. Source artwork retrieved on 2026-11-26.
